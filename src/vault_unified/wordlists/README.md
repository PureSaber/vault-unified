# EFF Long Wordlist

`eff_large_wordlist.txt` is the unmodified 7,776-word list by Joseph Bonneau /
Electronic Frontier Foundation, downloaded 2026-10-14 from:
https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt

Source and methodology: https://www.eff.org/dice
License: Creative Commons Attribution 4.0 International (CC BY 4.0), under
https://www.eff.org/copyright ; https://creativecommons.org/licenses/by/4.0/

Vault Unified chooses each word independently using Python `secrets.choice`.
The list is bundled for offline use; no runtime download is performed.
