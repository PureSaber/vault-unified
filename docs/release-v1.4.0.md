# Vault Unified v1.4.0

完整个人版：Windows 桌面端、Chrome／Edge 扩展和可选分享服务。
日常使用无需注册云账号；联网同步、分享、泄露检查和自动检查更新均默认关闭。

- 从浏览器 CSV 导入，预览重复与错误行；保存账号、改密、长期授权和重启重连。
- 收藏、标签、筛选排序、批量整理、重复合并、归档、30 天回收站及历史字段恢复。
- 验证码、二维码录入、口令短语与加密生成历史、恢复码／许可证／API 凭据模板。
- 输入框内选择、分步登录、多网址与排除规则、快捷搜索、托盘、Windows Hello、应用自动输入。
- 弱密码／重复密码检查、可选泄露查询、加密换机包和隔离恢复演练。
- 自选文件夹／WebDAV 的完整加密同步、离线重试、并发修改与删除冲突处理。
- Passkey 创建／登录、桌面确认、加密备份与 Vault Unified 设备间迁移。
- 限时分享、访问次数、撤销及独立家庭库，支持邀请、只读权限和移除成员后换钥。
- 主动检查更新、验证签名、更新前加密备份；EXE／MSI 和配套扩展使用相同版本。

## 安装与升级

下载 `Vault-Unified-Personal-v1.4.0-Windows-x64.zip`，解压后阅读 `START-HERE.md`。
EXE 和 MSI 任选其一；从 v1.3.0 升级时沿用原安装方式。升级前退出应用并保留加密备份。
新数据结构启用前会保留旧格式加密备份；旧客户端拒绝新结构，不能直接降级打开。

Chrome／Edge 扩展仍通过“加载已解压的扩展程序”安装。更新扩展时覆盖原目录并点击
“重新加载”，保留扩展身份和网站授权。只更新桌面应用不会自动替换手动加载的扩展。

Windows Hello 每次启动需先输入主密码；个人硬件认证见 `ACCEPTANCE.md`。
分享服务可用 Python 或 Docker Compose 单独部署，个人密码库不会自动进入共享库。
外部密码管理器的 Passkey 转换、手机 App、商店发布及商业 Authenticode 签名不在此版本范围。
